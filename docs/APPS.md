# Apps on Finch's frameworks

Which of Apple's own apps (`/System/Applications`, with Utilities) have every import
Finch's frameworks provide, and what the rest lack, ranked by how many apps each gap
blocks. Generated by `tools/app-sweep.py --markdown /System/Applications
/System/Applications/Utilities` over the build Mac's macOS 26.4, counting each app's
main executable and the frameworks it carries; weak imports don't count. Regenerate it
in any commit that changes what Finch's frameworks export. Third-party apps are swept
the same way locally (`tools/app-sweep.py` with no arguments) but aren't listed here.

Having every import is the first gate, not the last: an app that passes still has to be
run and checked (`docs/ROADMAP.md`, the app milestone).

**As of 2026-10-12:**
